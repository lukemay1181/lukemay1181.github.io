# OFF SZN — landing page recreation

This is a first-pass, editable recreation of the OFF SZN coming-soon page at https://fandom-offseason-threads.lovable.app/.

## Preview
Open `index.html` in your browser. It uses a remote image from the existing Lovable website and Google Fonts. The image might fail if the Lovable asset URL is restricted or changes. A dark gradient appears behind it.

## Current scope
- OFF SZN lifting club branding
- Fullscreen wall-and-shirts visual area
- Coming soon announcement and Instagram contact
- Mobile-responsive layout

This is **not** the site's exported Lovable source and is **not yet pixel-perfect**. The live page exposed limited content; spacing, overlays, typography, and supporting copy are approximations. No cart, payment collection, or custom-shirt request form is included.

## Where to edit
Change the heading, logo text, links, and social information directly in `index.html`. CSS is inside its `<style>` section.

## Hosting
This work is on the `off-szn-recreation` branch of the existing portfolio repository, isolated in `off-szn/`. The portfolio's `main` branch is unchanged. For a separate production store, create its own GitHub repository and connect it to Cloudflare Pages.

For higher fidelity, get access to your friend's Lovable source export and original image assets.
