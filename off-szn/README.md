# OFF SZN — interactive coming-soon website

Editable OFF SZN Lifting Club landing page with a three-shirt gallery, individual overhead spotlights, and responsive mobile carousel.

## Preview
Open `index.html` in a modern browser. Google Fonts are optional; local serif and sans-serif fonts are used as fallbacks.

## Interactions
- **Laptop/desktop**: All spotlights initially off. Hover a shirt to make it move forward slightly and activate its overhead lamp. The lamp flickers once, then stays on until the pointer leaves. Keyboard focus also activates it.
- **Mobile**: Swipe horizontally across the shirt gallery. The newly centered shirt flickers on. Previous/next arrows work too. The first shirt is initially illuminated.
- **Reduced motion**: Respects the `prefers-reduced-motion` accessibility preference.

## Files and edits
Everything is in `index.html`: markup, CSS, JavaScript, and the three inline SVG mockups. OFF SZN is centered on the front of each illustrated shirt. No external Lovable image assets are required.

## Notes
This is a **visual prototype**, not an operational shop, and includes no checkout or product order form. The shirts are illustrations, not real product photographs. The project is on the `off-szn-recreation` GitHub branch, under `off-szn/`; the portfolio site's `main` branch is unchanged.
